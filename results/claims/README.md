# Claim evidence — deferred

This directory is a layout placeholder, not claim evidence. The final package
must contain exactly one `results/claims/<claim-id>/manifest.json` plus its
referenced raw streams for each ID in `audit/claims.json`. Until
`tools/claim_audit.py validate-set results/claims` accepts the complete set and
the corresponding status gate is marked `passed`, no large certificate should
be described as reproduced by this repository.
